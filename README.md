Welcome to GeoPelago!
In order to run the randomizer you will need follow the instructions below.
  
  1. Download the .apworld file and either double click the file or drag and drop it onto your open Archipelago Launcher.
  2. Download the .yaml file provided and set it in your 'Players' folder along with any other worlds you would like to use. (Be sure to change the slot name within the file as it is currently default)
  3. Run and create your Archipelago room.
  4. Open the website, connect, and enjoy!
